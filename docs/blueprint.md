# **App Name**: AutoBill PWA

## Core Features:

- Product Management: Add, edit, and delete products with details like name, category, purchase price, selling price, stock quantity, and GST percentage. Includes a low stock indicator.
- Purchase Management: Record purchase entries with supplier details, invoice number, date, product, quantity, purchase price, and GST. Automatically updates stock levels.
- Sales Invoice Creation: Create sales invoices with product selection, quantity input, auto-calculated subtotal, GST, and total. Capture customer name and mobile number (optional) and generate a unique invoice number. The tool has the ability to help to follow up on invoices. The generated output should adhere to a printable invoice layout and save invoice history.
- Expense Tracking: Log daily expenses with details such as date, expense type, amount, and notes.
- Reporting & Downloads: Generate daily and monthly sales reports, profit summaries (sales - purchase - expenses), and stock reports. Download reports in PDF and CSV formats.
- Dashboard: Display key metrics like today's sales total, monthly sales, total expenses, and current stock value in one consolidated admin panel. Allow single shop owner login and enable user management features with read, write and edit privileges to different users in a single place.
- Admin Authentication: Simple admin management and login creation tool.

## Style Guidelines:

- Primary color: Light purple (#B092FF) for a clean and modern look.
- Background color: Very light purple (#F5F3FF), almost white, for a clean backdrop that does not distract from the data.
- Accent color: Blue (#7B66FF), to complement the primary purple and provide clear contrast for interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif with a modern and neutral look.
- Use simple, minimalist icons for clear navigation. The icons should be white when on the primary purple, and the icons should be darker (more saturated version of the primary) when used on the light purple background.
- Maintain a clean, responsive layout for optimal viewing on both mobile and desktop devices. Use a clear navigation system.
- Incorporate subtle animations to enhance user experience during data loading and form submissions.
